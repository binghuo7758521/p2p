# 无限大盘 P2P 文件传输系统 安全运维管理

## 第一章 环境管理

**第一条** 系统运行环境为阿里云 ECS 云主机（由云服务商提供机房物理安全），部署范围如下：

| 项目 | 配置 |
|---|---|
| 服务器 | 阿里云 ECS（Linux），运行 Node.js 信令服务（端口 3000） |
| 升级包分发 | OSS 及服务器下载目录 |
| 域名 | wuxiandapan.com（HTTPS 改造后使用） |

**第二条** 服务器应遵循：

1. 仅开放业务所需端口（3000，HTTPS 改造后为 443），其余端口在安全组中关闭；
2. SSH 登录使用密钥认证，禁用弱口令；
3. 及时更新操作系统与运行环境安全补丁；
4. 云主机安全组变更须经审批（见《安全管理机构》第七条）。

## 第二章 资产管理

**第三条** 建立资产台账，登记服务器、域名、证书、密钥、软件组件及其责任人与有效期，至少每半年核对一次。

**第四条** 关键数据资产清单：

1. 用户与凭证数据：users.json、tokens.json、host-tokens.json、host-codes.json；
2. 共享与授权数据：shares.json、join-relations.json、licenses.json、act-devices.json；
3. 密钥资产：ENC_KEY（AES-256-GCM 加密密钥，存于服务器环境变量 env.sh，权限仅 root）；
4. 数字证书：HTTPS TLS 证书（有效期到期前 30 天预警续签）。

## 第三章 日志审计

**第五条** 服务日志（server.log）记录关键操作事件：激活码签发与使用、设备配对、令牌签发、管理后台操作、异常错误等。

**第六条** 日志管理要求：

1. 日志文件滚动保存（按大小分割），保留周期不少于 6 个月；
2. 禁止在日志中记录口令、令牌、密钥等敏感信息；
3. 安全管理员定期（每月）检查日志，发现异常（多次失败尝试、越权操作、异常 IP）及时处置并记录；
4. 重大安全事件日志留存不少于 6 个月。

## 第四章 备份与恢复

**第七条** 每日自动备份：

1. 备份脚本 /opt/p2p-app/backup.sh，由 crontab 于每日 02:30 自动执行；
2. 备份内容：全部敏感数据文件（users.json、tokens.json、shares.json、act-devices.json、host-tokens.json、host-codes.json、join-relations.json、licenses.json）；
3. 备份保存至 /opt/p2p-backups/ 目录，按日期时间分目录存放；
4. 保留策略：备份保留 30 天，超期自动清理；
5. 系统管理员每日检查备份日志（/var/log/p2p-backup.log），确认备份成功。

**第八条** 恢复流程：

1. 定位需恢复的备份目录（按日期选择最近一次成功备份）；
2. 停止服务 → 将备份文件复制回 /opt/p2p-app/ 数据目录 → 启动服务；
3. 验证数据完整性：管理员登录、设备重连、共享列表显示均正常；
4. 记录恢复操作（时间、原因、备份点、结果）。

**第九条** 备份恢复演练：安全管理员每半年至少组织一次恢复演练，验证备份数据可用性与恢复流程有效性，演练记录归档。

## 第五章 变更管理

**第十条** 以下变更须填写变更申请并审批后执行：

1. 服务器配置、安全组、端口变更；
2. 数据文件手工修改或删除；
3. 密钥、证书的生成与更换；
4. 新版本发布（按《安全建设管理》第四章流程执行）。

**第十一条** 变更应在业务低峰期执行，变更前先执行一次手动备份，变更后验证服务正常并记录变更结果。

## 第六章 应急处理

**第十二条** 应急场景及处置：

| 场景 | 处置措施 |
|---|---|
| 服务异常/宕机 | 检查服务状态与日志 → 重启服务 → 若数据异常则从最近备份恢复 |
| 数据文件损坏/丢失 | 停止服务 → 用备份恢复 → 验证 → 恢复服务 |
| 疑似入侵/异常访问 | 立即断开外部访问 → 保留现场日志 → 通知安全负责人 → 排查加固 |
| 证书过期 | 提前 30 天预警，到期前完成续签并重新部署 |
| 密钥泄露 | 立即更换 ENC_KEY → 重启服务 → 评估受影响数据并重加密 |

**第十三条** 安全事件响应时限：安全管理员发现或接到报告后 1 小时内报告安全负责人，重大事件 4 小时内采取控制措施。

**第十四条** 应急演练：每半年至少开展一次应急演练（服务恢复、备份恢复），演练记录归档；应急联系人及电话登记备案并保持更新。
